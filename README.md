
# COS 201 - Computer Programming I
## Week 3 Assignment

This repository contains three Java programs developed for the COS 201 Week 3 assignment.

### 1. SimpleCalculator.java
A simple calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

### 2. AverageCalculator.java
A program that accepts three numbers and calculates their average.

### 3. ItemCost.java
A program that accepts an item name, quantity, and price per item, then calculates the total cost.

## How to Compile and Run

Make sure Java JDK is installed on your computer.

### SimpleCalculator
javac SimpleCalculator.java
java SimpleCalculator

### AverageCalculator
javac AverageCalculator.java
java AverageCalculator

### ItemCost
javac ItemCost.java
java ItemCost
